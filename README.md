# 世界地理地图（微信小程序）

给学生学习世界地理用的地图小程序，地图部分基于小程序原生 `<map>` 组件（腾讯地图）。

## 运行

1. 安装并打开「微信开发者工具」，选择「导入项目」，目录选本文件夹。
2. AppID 先用自带的测试号即可预览；正式发布前把 `project.config.json` 里的 `appid` 换成你自己的。
3. 点「预览」用手机扫码，双指缩放要在真机上体验。

## 页面

| 目录 | 内容 |
| --- | --- |
| `pages/index` | 地图：搜索、分类筛选、图层面板、缩放、知识卡片 |
| `pages/library` | 知识库：按国家 / 大洲大洋 / 山河湖海分类的列表，点一行回到地图定位 |
| `pages/quiz` | 测验入口：地图找点（国家、大洲大洋、山河湖海）和知识问答，查看最近成绩 |
| `pages/play` | 地图找点的答题和成绩页（不在底部导航里） |
| `pages/ask` | 知识问答（选择题）的答题和成绩页 |
| `pages/me` | 我的学习：学习进度、需要复习、学习清单 |

## 地图功能

- 缩放：双指捏合、右侧 ＋/－ 按钮、底部滑块，级别 3–12，实时显示当前级别和中心坐标。
- 随缩放切换内容：远景显示七大洲、四大洋；放大后显示国家和首都；再放大显示山脉、河流、海峡等。
- 图层面板：标准地图 / 卫星影像切换，各类知识点开关，赤道、回归线、极圈开关。
- 知识卡片：国家显示首都、位置、面积、人口和简介，可加入学习清单。

## 课堂教学

- 专题课：地图右侧「课程」或知识库的「专题课」里选一个主题（七大洲、四大洋、大洲分界线、世界之最等），地图上只留这节课的知识点并编号，用「上一个 / 下一个」逐个讲解。课程内容在 `data/lessons.js`，可以自己增删。
- 五带：图层里打开后，用色块标出热带、南北温带、南北寒带。
- 自测：图层里打开「隐藏名字」后，标记只显示“？”，先自己说出名字，再点开看答案。

## 高中内容

- 知识点：洋流、四大渔场、六大板块、气压带和风带、气候类型（筛选里的「高中自然」，默认不显示）。
- 专题课：世界洋流、四大渔场、六大板块、气压带和风带、气候类型。
- 图层：洋流流向（红色暖流、蓝色寒流的箭头）、气压带和风带（色带加风向箭头）、气候类型和自然带、1 月等温线。上相关专题课时会自动临时打开。
- 气候类型、自然带、等温线、洋流路径都是手工画的**示意图**（数据在 `data/climate.js` 和 `pages/index/index.js`），只表示大致位置和规律，不是精确数据。
- 知识问答：时区计算、自然地理两个专题；国家专题里有按经纬度定位的题。
- 国家和山河湖海的卡片显示经纬度和按经度计算的理论时区。
- 错题重练：测验页可以只练复习清单里的知识点，一次找对就移出清单。

## 数据

- 所有知识点在 `data/geo.js`：大洲、大洋、国家、山河湖海、区域、经纬线与五带六类，照着已有格式加一条就会出现在地图、知识库和测验里。
- 重点国家和地区的“知识要点”在 `data/geo.js` 的 `KEY_POINTS` 里。
- 选择题由 `utils/questions.js` 根据知识点自动生成。
- 面积、人口均为约数，正式用于教学前请按教材或最新统计核对。
- 学习记录（已学、学习清单、需要复习、测验成绩）用 `utils/store.js` 存在手机本地。
