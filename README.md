# GeoQuest 世界地理知识游戏（微信小程序）

按 GeoQuest v4.1 的设计稿和 PRD 写的原生小程序：十题挑战（地图找国家、国旗竞猜、限时混合）、国家拼图、回顾订正、每日任务、成就、记录、图鉴、同题邀请。数据全部存在本机，没有服务器。

## 运行

1. 用微信开发者工具「导入项目」，目录选本文件夹。
2. `project.config.json` 里的 `appid` 是占位的测试号，发布前换成自己的。
3. 地图的拖动、双指缩放和拼图的拖动放置，请用「预览」在真机上试。

## 规则和数据在哪里

- `utils/engine.js`：十题局的全部规则（3 颗心、每题 30 秒、提示和跳过、判题只认第一次、结算、星级、奖励）。
- `utils/puzzle.js`：拼图规则（4% 吸附、点选放置、提示一次、追问可订正、首次通关 +10 经验）。
- `utils/progress.js`：等级、每日任务、成就、连续学习天数。`utils/insight.js`：“最近容易错的”统计。`utils/code.js`：挑战码。`utils/store.js`：本机存档。
- `data/countries.js`：国家内容包（定位提示、讲解、追问、国旗线索）。
- `data/puzzles.js` 和 `images/puzzle/`：拼图关卡和碎片图。
- `data/world.js` 和 `components/geo-map`：示意世界地图和画图组件。

## 和 PRD 的差别（重要）

- **世界地图是手绘的示意图。** 海岸线和国界只表示大致位置，不是测绘数据；南美洲各国的轮廓取自设计稿源文件。收录了 51 个国家，其余陆地点了不算作答。正式发布前必须换成经过审校、适合发行地区的地图数据。
- **国旗有 32 面**：15 面来自设计稿源文件，17 面是按国旗的几何构成用程序画的（只画了条纹和简单图形的国旗，颜色凭常用值，没有对照标准色）。带徽章的国旗没有画，这些国家只出地图题，图鉴里标“国旗素材待补”。
- **拼图的切片是程序按面积均分切出来的直线切片**（巴西入门 4 片用了设计稿的带卡扣模板）。共 12 个国家；智利太狭长、日本的手绘轮廓认不出来，没有做成关卡。设计稿里巴西 6 片、9 片的模板有空片，不符合 PRD 的发布校验，所以没有用。
- **没有服务器。** 挑战码由玩法、出题种子和日期算出来，两台手机内容版本相同时输入同一个码会得到同一套题；但成绩只存本机，也没有服务端复核。因此没有做“本题好友榜”和“是否公开”的开关，排行榜页的第二栏改成了“我的同题挑战”，只列自己参加过的挑战和首次成绩。
- **没有朗读**，题卡上没放朗读按钮。
- **没有做**单人世界徒步探险和多人徒步大富翁（v4.2、v4.3）。
- 每日任务每天固定派“轮廓侦探”“地图侦察员”，第三个在“国旗观察员”和“错题修复师”之间轮换。
