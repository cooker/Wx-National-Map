# 世界地理地图（微信小程序）

给学生学习世界地理用的地图小程序，地图部分基于小程序原生 `<map>` 组件（腾讯地图）。

## 运行

1. 安装并打开「微信开发者工具」，选择「导入项目」，目录选本文件夹。
2. AppID 先用自带的测试号即可预览；正式发布前把 `project.config.json` 里的 `appid` 换成你自己的。
3. 点「预览」用手机扫码，双指缩放要在真机上体验。

## 页面

| 目录 | 内容 |
| --- | --- |
| `pages/index` | 地图：搜索、分类筛选、图层面板、缩放、知识卡片 |
| `pages/library` | 知识库：按国家 / 大洲大洋 / 山河湖海分类的列表，点一行回到地图定位 |
| `pages/quiz` | 测验入口：选出题范围，查看最近成绩 |
| `pages/play` | 答题和成绩页（不在底部导航里） |
| `pages/me` | 我的学习：学习进度、需要复习、学习清单 |

## 地图功能

- 缩放：双指捏合、右侧 ＋/－ 按钮、底部滑块，级别 3–12，实时显示当前级别和中心坐标。
- 随缩放切换内容：远景显示七大洲、四大洋；放大后显示国家和首都；再放大显示山脉、河流、海峡等。
- 图层面板：标准地图 / 卫星影像切换，各类知识点开关，赤道、回归线、极圈开关。
- 知识卡片：国家显示首都、位置、面积、人口和简介，可加入学习清单。

## 数据

- 所有知识点在 `data/geo.js`，照着已有格式加一条就会出现在地图、知识库和测验里。
- 学习记录（已学、学习清单、需要复习、测验成绩）用 `utils/store.js` 存在手机本地。
